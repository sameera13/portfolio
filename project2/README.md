
# Client Journey Visualization Dashboard

**Repository:** https://github.com/sameera13/sankey-app

## Overview
This is a React-based web application designed to visualize client journeys through various service touchpoints using an interactive Sankey diagram. Users can upload Excel files containing session and event data to analyze customer flows and drop-off points.

## Key Features
- Excel file upload
- Interactive Sankey diagram
- Node percentages
- Hover details
- Client filtering
- Session summary
- Responsive design

## Tech Stack
- React
- Plotly.js
- SheetJS
- Tailwind CSS

## Getting Started
```bash
git clone https://github.com/sameera13/sankey-app
cd sankey-app
