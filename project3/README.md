

# Horizon Mobile Plans API

**Repository:** https://github.com/Horizon-MV/Horizon-App

## Overview
Horizon-App is a Spring Boot backend application for managing users and mobile plans, featuring secure authentication with Auth0 (OIDC), role-based access control, and REST APIs for CRUD operations.

## Key Features
- Auth0 authentication
- Role-based access control
- CRUD operations for users and plans
- H2 in-memory database
- REST API architecture

## Tech Stack
- Java 17
- Spring Boot
- Spring Security
- OAuth2 / OIDC
- JPA / Hibernate
- H2 Database

## Getting Started
```bash
git clone https://github.com/Horizon-MV/Horizon-App.git
cd Horizon-App
