

# FitLog – Wellness & Habit Tracker

**Repository:** https://github.com/Wellness-Tracker/FitLog  
**Live Demo:** https://fitlogg-qssq.onrender.com/

## Overview
FitLog is a modern single-page wellness tracker built with React, Vite, and React-Bootstrap. It helps users log meals, workouts, habits, and progress using a clean dashboard layout.

## Key Features
- SPA routing
- Meals CRUD
- Workouts CRUD
- Habit tracker
- Progress page
- Settings page

## Tech Stack
- React
- Vite
- React Router
- React Bootstrap

## Getting Started
```bash
git clone https://github.com/Wellness-Tracker/FitLog
cd FitLog
npm install
npm run dev
